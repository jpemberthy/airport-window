# Independent forks

This is an unmaintained source release. No support, issue triage, pull-request review or future releases are promised. Create your own fork, use the porting guide, and maintain your installation independently. A working airport pack is an example, not a promise to support that airport indefinitely.

The repository is archived after the v1 handoff to make this boundary explicit. LoganWatch remains a separate personal project. No changes here are automatically synchronized to it, and no future LoganWatch work is automatically published here.
